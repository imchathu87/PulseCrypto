- (capability by spec) CAP-3 Slow or stalled clients cannot cause unbounded backend memory growth.

- (capability by spec) CAP-8 User can search/filter pairs (typing btc leaves BTC / USDT).

- (capability by spec) CAP-11 Price up briefly highlights green, down red; order book volume changes animate smoothly.
- (capability by spec) CAP-12 UI stays smooth and responsive during sustained update bursts.
- (capability by spec) CAP-13 When backend unavailable app shows connection status, keeps last data visible, reconnects automatically when backend returns.
